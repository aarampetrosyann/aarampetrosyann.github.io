What I learned building a tiny analytics pipeline

SQLite, a cron job, and why I stopped reaching for a dashboard first.

Aram · September 30, 2026 · 8 min read

A few months ago I wanted to know one small thing: which pages on this site people actually read. Every tool I tried wanted to be a platform.1 I wanted a table.

The whole setup

Three pieces: a tiny endpoint that logs a row, a SQLite file, and a nightly job that rolls the rows up. That's genuinely it.

-- daily views per path
INSERT INTO daily (day, path, views)
SELECT date(ts), path, count(*)
FROM hits
WHERE date(ts) = date('now', '-1 day')
GROUP BY 1, 2;

Why not a dashboard

Dashboards answer questions you haven't asked yet. A query answers the one you have. Writing the SQL by hand made me decide what I actually cared about.

“The smallest tool that answers the question is usually the right one.”

What's next

I'll probably add referrers next, then stop. If you've built something similar, I'd love to hear how you kept it small.
