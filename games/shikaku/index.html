Shikaku

A grid-splitting puzzle. Divide the grid into rectangles that match the numbers inside them.

Grid size
Difficulty

How to play

  1. Divide the whole grid into rectangles. Squares count as rectangles too.
  2. Every rectangle contains exactly one number.
  3. That number is the rectangle’s area: how many cells it covers.
